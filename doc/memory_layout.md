## System Memory Layout
| Device | Start Address | End Address | Size |
| :--- | :---: | :---: | ---: |
| BOOT VECTORS    | 0x00000000 | 0x00000007 | 8 Bytes |
| FAST RAM        | 0x00000000 | 0x000003FF |    1 KB |
| SDRAM 8MB       | 0x00000000 | 0x007FFFFF | 8192 KB |
| SDRAM 4MB       | 0x00800000 | 0x00BFFFFF | 4096 KB |
| SDRAM 2MB       | 0x00C00000 | 0x00DFFFFF | 2048 KB |
| VIDEO FB        | 0x02000000 | 0x0201FFFF |  128 KB |
| LED PERIPH      | 0x02100000 | 0x02103FFF |   16 KB |
| UART PERIPH     | 0x02104000 | 0x02107FFF |   16 KB |
| VIDEO PALETTE   | 0x02108000 | 0x0210BFFF |   16 KB |
| VIDEO CONTROL   | 0x0210C000 | 0x0210FFFF |   16 KB |
| COUNTER         | 0x02110000 | 0x02113FFF |   16 KB |
| LED_ARRAY       | 0x02114000 | 0x02117FFF |   16 KB |
| USB HID HOST    | 0x02118000 | 0x0211BFFF |   16 KB |
| TIMER           | 0x0211C000 | 0x0211FFFF |   16 KB |
| SPI             | 0x02120000 | 0x02123FFF |   16 KB |
| PSG             | 0x02124000 | 0x02127FFF |   16 KB |
| DS1302          | 0x02128000 | 0x0212BFFF |   16 KB |
| DIP SWITCHES    | 0x0212C000 | 0x0212FFFF |   16 KB |
| CACHE STATS     | 0x02130000 | 0x02133FFF |   16 KB |
| MAIN ROM        | 0x021C0000 | 0x021C3FFF |   16 KB |
